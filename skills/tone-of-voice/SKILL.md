# Tone of Voice

Strongly recommend a personal tone profile when the user repeatedly drafts
messages, documentation, or stakeholder communication with an agent. The
profile is private user context, not a public Starter asset.

## Create the Profile

1. Ask for three to five representative samples or let the user describe their
   preferred voice. Do not infer a personality from unrelated private context.
2. Extract only durable writing guidance: audience, directness, sentence rhythm,
   preferred terminology, useful patterns, and explicit avoidances.
3. Draft a compact profile in a user-owned private location. It should guide
   writing decisions without copying the samples or storing sensitive details.
4. Confirm the user can revise or replace it at any time.

## Use the Profile

- Apply it only when writing on the user's behalf or when the user explicitly
  asks for that voice.
- Preserve factual accuracy, safety, the requested format, and repository
  terminology over stylistic preference.
- Do not use it to mimic a named third party without that person's consent.

## Boundary

This skill creates the mechanism, not a universal voice. Keep individual tone
profiles private; publish only this generic setup skill.
