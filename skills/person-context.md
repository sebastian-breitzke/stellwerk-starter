# Skill Blueprint: Person Context

Person Context is for durable communication and collaboration preferences.

It is not a dossier and not a meeting archive.

## Use When

- writing to or for a known person
- preparing for a conversation
- interpreting stakeholder communication style
- extracting durable collaboration signal from meeting notes

## Store Only

- role and collaboration surface
- preferred level of detail
- communication style
- decision criteria
- recurring work concerns
- how to write with or for the person

## Do Not Store

- gossip
- private leverage
- diagnoses
- HR-style performance judgments
- one-off moods
- transcripts
- chronological event logs

## Update Rule

Meeting recaps may propose person-context candidates, but persistence requires
explicit user approval.

Suggestion shape:

```text
Person Context To Review:

- <Person>: check whether this is durable: <communication or collaboration signal>
```

## Privacy Boundary

Person context is private by default. Do not put it in public repos, customer
repos, or generic starter material.
