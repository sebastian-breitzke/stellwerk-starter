# Canonical Starter Skills

The public Starter uses the same skill names as the portable Stellwerk source.
Install only the skills the user's work needs; a smaller sharp library routes
better than a broad default installation.

| Work | Skill |
|---|---|
| Long-running, multi-step work | `leitstand` |
| Planning pressure | `dev-challenge` |
| Change orchestration | `dev-implement` |
| Tests, debugging, and proof | `dev-discipline` |
| Architecture fit | `dev-review` |
| Line-level shippability | `dev-code-review` |
| Canonical domain terms | `dev-domain-language` |
| Product UI work | `dev-ui` |
| Requested GitHub PR loop | `dev-github-pr` |
| Commit and PR prose | `dev-change-notes` |
| Prompt and skill contracts | `prompt-creation-review` |
| Durable functional prose | `functional-writing` |
| Repo agent-experience review | `ax-review` |
| Architecture pragmatism | `smb-pragmatism` |
| Conservative prose cleanup | `unslop` |
| Private writing profile setup | `tone-of-voice` |
| Safe local credential routing | `secret-resolution` |
| Local media transcription | `transcription` |
| YouTube research | `youtube-research` |

`dev-implement` sequences delivery; `dev-discipline` supplies evidence;
`dev-review` judges design; and `dev-code-review` judges a finished diff. Do not
collapse those jobs into one broad skill.

`brave-search`, `research`, and `meeting-recap` remain classified extensions:
their canonical public release waits for the remaining genericization or setup
guidance. Private integrations and personal profiles are never copied here.
